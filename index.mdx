Herdr is the runtime your coding agents live on. It keeps real terminal processes alive in a background server when you close your client, lose SSH, or walk away — then restores the full workspace when you return. Every agent's `working`, `blocked`, `done`, or `idle` state is visible at a glance, so you always know which project needs you.

## Get started in 3 steps

<Steps>
  <Step title="Install">
    ```bash
    curl -fsSL https://herdr.dev/install.sh | sh
    ```
    Or `brew install herdr` · `mise use -g herdr` · [Windows installer](/install#windows)
  </Step>
  <Step title="Launch">
    Start Herdr from your project directory. It runs a background server and attaches a terminal UI.
    ```bash
    herdr
    ```
  </Step>
  <Step title="Run agents, then detach">
    Start your coding agent. Press `ctrl+b q` to detach — your agents keep running.
    ```bash
    claude
    # ... let it work, then ctrl+b q to detach
    # Later:
    herdr   # reattach to the same session
    ```
  </Step>
</Steps>

## Supported agents

Herdr natively detects Claude Code, Codex, Cursor, OpenCode, Grok, and [many more](/agents). Agents that report their own state — like Command Code and Crush — need no setup at all. If you build a coding agent, [add Herdr support](/add-herdr-support) in a few API calls with no changes to Herdr itself.
