Herdr publishes stable-channel binaries for Linux, macOS, and Windows. Windows is generally available, with documented platform-specific limitations and ongoing fixes. The fastest path on Linux and macOS is the one-line curl installer; all other methods are described below.

## Primary installation

<Steps>
  <Step title="Run the installer">
    <Tabs>
      <Tab title="Linux / macOS">
        ```bash
        curl -fsSL https://herdr.dev/install.sh | sh
        ```
      </Tab>
      <Tab title="Windows (PowerShell)">
        ```powershell
        powershell -ExecutionPolicy Bypass -c "irm https://herdr.dev/install.ps1 | iex"
        ```

        If endpoint security blocks that fileless PowerShell command, open Command Prompt and run:

        ```cmd
        curl.exe -fsSLo install.cmd https://herdr.dev/install.cmd && install.cmd && del install.cmd
        ```

        <Note>
          On Windows, PATH points to the active versioned release directory. The installer also updates the `current` and stable `bin` compatibility aliases, so updates do not need to overwrite a running `herdr.exe`.
        </Note>
      </Tab>
    </Tabs>

    The installer downloads the release binary for your platform and places it on your PATH. New direct installs use the stable update channel.
  </Step>

  <Step title="Verify the install">
    Start Herdr:

    ```bash
    herdr
    ```

    If your shell cannot find `herdr`, restart the terminal or check that the install directory is on your PATH.
  </Step>
</Steps>

## Install with a package manager

<Tabs>
  <Tab title="Homebrew">
    If you already use Homebrew:

    ```bash
    brew install herdr
    ```
  </Tab>
  <Tab title="mise">
    If you already use mise:

    ```bash
    mise use -g herdr
    ```

    <Note>
      If mise reports `herdr not found in mise tool registry`, update mise and retry. Older mise versions predate the Herdr registry entry. Use `mise use -g github:herdrdev/herdr` as a temporary fallback.
    </Note>
  </Tab>
  <Tab title="Nix">
    If you already use Nix, Herdr provides a flake that builds Herdr from source:

    ```bash
    nix run github:herdrdev/herdr/v0.x.y
    nix build github:herdrdev/herdr/v0.x.y
    nix profile install github:herdrdev/herdr/v0.x.y
    ```

    Replace `v0.x.y` with the latest release tag. You can omit the tag to track `master`, but release tags are recommended for normal installs.

    The flake also exposes a development shell:

    ```bash
    nix develop github:herdrdev/herdr
    ```
  </Tab>
</Tabs>

## Download manually

You can also download a binary directly from [GitHub releases](https://github.com/herdrdev/herdr/releases). Choose the asset that matches your system:

| System | Asset |
| --- | --- |
| Linux x86\_64 | `herdr-linux-x86_64` |
| Linux aarch64 | `herdr-linux-aarch64` |
| macOS Intel | `herdr-macos-x86_64` |
| macOS Apple silicon | `herdr-macos-aarch64` |
| Windows x86\_64 | `herdr-windows-x86_64.zip` |

On Linux or macOS, make the binary executable and move it somewhere on your PATH:

```bash
chmod +x herdr-linux-x86_64
mv herdr-linux-x86_64 ~/.local/bin/herdr
```

### Windows archive

Stable releases and preview prereleases both include `herdr-windows-x86_64.zip`. The archive contains `herdr.exe` and its app-local ConPTY runtime. Keep the extracted directory together; do not copy only `herdr.exe`.

## Update

Herdr checks for new releases and notifies you in the app. You can also update manually:

```bash
herdr update
```

<Warning>
  Use `herdr update` only for installs managed by Herdr's own installer. Update Homebrew, mise, and Nix installs through those package managers instead.
</Warning>

By default, `herdr update` installs the new binary and leaves running servers and their pane processes running. Start Herdr again to reconnect with the updated client.

When it finishes, `herdr update` lists any running server still on the old version with the command that restarts it, and your saved SSH machines. Run `herdr update` on each machine to update it too.

### Live server handoff

To opt into experimental live server handoff for supported running sessions:

```bash
herdr update --handoff
```

When both servers support agent-status transfer, live handoff preserves hook-reported agent status until the next report arrives.

<Note>
  Live handoff does not apply to Homebrew, mise, or Nix package-manager updates. For those installs, update with the package manager, then run Herdr again to reconnect.
</Note>

## Switch release channels

Direct installs use the **stable** channel by default. To opt into preview builds from `master`:

```bash
herdr channel set preview
```

Switch back to stable the same way:

```bash
herdr channel set stable
```

<Tip>
  Preview builds are regularly published prereleases from the current development branch. They are useful when you want fixes before the next stable release, but they can regress. Stable is the recommended channel for normal use — especially on Windows.
</Tip>

Existing Windows preview installs remain on preview until you switch them explicitly. If an older preview build rejects `herdr channel set stable`, run `herdr update` once on preview, then retry the channel switch.

Homebrew, mise, and Nix installs do not use the preview channel.

## Requirements

Stable-channel binaries are available for Linux, macOS, and Windows x86\_64. Windows ARM64 runs the x86\_64 build under Windows emulation. See the [Windows support](https://herdr.dev/docs/windows-beta/) page for supported workflows and known limitations.
