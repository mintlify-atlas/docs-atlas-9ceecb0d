Herdr reads a single `config.toml` file at startup. Every key documented here is canonical — Herdr ignores unknown keys and applies defaults for any key you omit. To see the full commented default configuration at any time, run:

```bash
herdr --default-config
```

Most settings are reloadable at runtime without restarting panes:

```bash
herdr server reload-config
```

Settings that require a restart or reattach are noted in their descriptions below.

## General

Top-level keys not nested under a section.

| Key | Type | Default | Description |
|---|---|---|---|
| `onboarding` | boolean | unset | Show first-run setup on startup. Missing or `true` shows onboarding; completing onboarding writes `onboarding = false`. |

## `[server]`

Controls the virtual terminal dimensions used when no client is attached (headless mode).

| Key | Type | Default | Description |
|---|---|---|---|
| `server.headless_cols` | integer | `120` | Virtual terminal width for layout and newly created panes when no client is attached. Must be greater than zero. |
| `server.headless_rows` | integer | `40` | Virtual terminal height for layout and newly created panes when no client is attached. Must be greater than zero. |

## `[terminal]`

Controls shell selection, startup mode, and working-directory policy for new panes.

| Key | Type | Default | Description |
|---|---|---|---|
| `terminal.default_shell` | string | `""` | Executable for new interactive panes. Empty means `$SHELL`, then `/bin/sh`; on Windows, `pwsh.exe` when available on `PATH`, otherwise `powershell.exe`. |
| `terminal.shell_mode` | enum | `"auto"` | Startup mode for new interactive pane shells: `auto`, `login`, or `non_login`. |
| `terminal.new_cwd` | enum | `"follow"` | CWD policy for new interactive panes, tabs, and workspaces: `follow` (source pane or workspace), `home`, `current`, or `path`. |
| `terminal.kitty_graphics` | boolean | `true` | Render pane images in Kitty graphics-compatible outer terminals. Set `false` to disable. Restart the server or reattach the client after changing. In remote sessions, the server config controls parsing; the local client config controls outer-terminal output. |

## `[update]`

Controls automatic version and manifest update checks.

| Key | Type | Default | Description |
|---|---|---|---|
| `update.channel` | enum | `"stable"` | Update channel for background version checks and `herdr update`: `stable` or `preview`. Stable Windows builds default to `stable`; existing Windows preview installs stay on `preview` until explicitly switched. Homebrew, mise, and Nix installs ignore the preview channel. |
| `update.version_check` | boolean | `true` | Check herdr.dev for new Herdr versions in the background. |
| `update.manifest_check` | boolean | `true` | Check herdr.dev for remote agent-detection manifest updates in the background. Bundled manifests and local overrides still apply when disabled. |

| Key | Type | Default | Description |
|---|---|---|---|

| `session.startup_per_agent_delay_ms` | integer | `100` | Milliseconds between automatic agent restores after a server restart. The first agent starts without this delay; `0` disables spacing. Does not delay manual launches or explicit terminal attaches. Restart the server to apply. |

## `[ui]`

Controls the overall UI layout, mouse behavior, sidebar dimensions, pane borders, and tab bar configuration.

### Mouse and focus

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.mouse_capture` | boolean | `true` | Capture mouse input for Herdr's mouse UI. |
| `ui.copy_on_select` | boolean | `true` | Automatically copy text selected by mouse drag or double-click. When disabled, Ctrl+C or a host-forwarded Cmd+C copies and clears the retained selection. |
| `ui.mouse_scroll_lines` | integer | `3` | Lines to scroll per mouse wheel notch. |
| `ui.host_cursor` | enum | `auto` | Host cursor policy: `auto`, `native`, or `drawn`. |
| `ui.right_click_passthrough_modifier` | string | `""` | Modifier that lets right-click gestures pass through to pane apps. Empty disables it. Accepts `ctrl`, `alt`, `cmd`, `super`, `meta`, `hyper`, or a `+`-separated combination. `shift` is rejected. |
| `ui.redraw_on_focus_gained` | boolean | `true` | Force a full host-terminal redraw when the outer terminal regains focus. |

### Sidebar layout

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.sidebar_width` | integer | `26` | Default expanded sidebar width in columns. Auto-scales based on workspace names. |
| `ui.sidebar_min_width` | integer | `18` | Minimum sidebar width in columns when expanded. |
| `ui.sidebar_max_width` | integer | `36` | Maximum sidebar width in columns when expanded. |
| `ui.sidebar_start_collapsed` | boolean | `false` | Start Herdr with the sidebar collapsed. Takes effect on the next launch. |
| `ui.sidebar_collapsed_mode` | enum | `compact` | Collapsed sidebar presentation: `compact` or `hidden`. |
| `ui.mobile_width_threshold` | integer | `64` | Terminal width at or below which Herdr uses the mobile single-column layout. |

### Confirmation and naming prompts

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.confirm_close` | boolean | `true` | Ask for confirmation before closing a workspace from the TUI. Ordinary CLI/API closes remain immediate. |
| `ui.prompt_new_tab_name` | boolean | `true` | Ask for a tab name before creating a new tab from the TUI. |
| `ui.prompt_new_workspace_name` | boolean | `false` | Ask for a workspace name before interactive TUI workspace creation. |

### Pane appearance

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.pane_borders` | enum | `"auto"` | Draw borders around split panes. `auto`: only for split panes. `always`: also frames a lone pane (requires `pane_outer_borders`). `off`: disabled. Legacy booleans parse: `true` → `auto`, `false` → `off`. |
| `ui.pane_outer_borders` | boolean | `true` | Draw borders along the outside edge of the pane area. Disable with `pane_gaps` disabled for tmux-style internal splitters without an outside frame. |
| `ui.pane_scrollbars` | boolean | `true` | Draw interactive scrollbars beside terminal panes. |
| `ui.pane_gaps` | boolean | `true` | Keep split panes visually separated instead of sharing divider borders. |
| `ui.show_agent_labels_on_pane_borders` | boolean | `false` | Show agent labels in split pane borders when no manual pane label is set. |

### Tab bar

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.hide_tab_bar_when_single_tab` | boolean | `false` | Hide the tab row when the workspace has only one tab. |
| `ui.tab_bar_position` | enum | `"top"` | Place the tab row `top` or `bottom` relative to terminal panes. |
| `ui.tab_bar_right` | array | `[]` | Ordered right-aligned tab bar entries. Supported types: `zoom`, `hostname`, `datetime`, `text`, `command`. |
| `ui.tab_bar_right_separator` | string | `" "` | Text inserted between visible right-aligned tab bar entries. |

### Window title

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.window_title` | string | `"{hostname}: {workspace}"` | Title written to the terminal Herdr runs in. Tokens: `{hostname}`, `{workspace}`, `{tab}`, `{pane}`, `{terminal_title}`. Empty leaves the outer title unchanged. |

### Agent panel

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.agent_panel_sort` | enum | `"spaces"` | Agent sidebar ordering: `spaces` (by workspace; `workspaces` is an accepted alias) or `priority`. |
| `ui.status_indicators` | enum | `"dots"` | Agent state indicators: `dots` (compact color dots) or `symbols` (distinct static symbols). |
| `ui.accent` | color | `"cyan"` | Accent color for highlights, borders, and navigation UI. Accepts hex (`#89b4fa`), named colors (`cyan`, `blue`), or RGB (`rgb(137,180,250)`). |

## `[ui.sidebar]`

Controls the layout of Agent and Space rows in the expanded sidebar.

### Agent rows

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.sidebar.agents.row_gap` | integer | `0` | Blank terminal rows between expanded Agent sidebar entries. Set to `1` to restore the previous spacing. |
| `ui.sidebar.agents.rows` | list of token rows | `[["state_icon", "machine", "workspace", "tab"], ["agent"]]` | Default expanded Agent sidebar layout. Entries may be token strings or inline `{ token, fg, bold, dim, rules }` style tables. Up to 16 rows, 16 tokens per row. |
| `ui.sidebar.agents.rows_by_agent` | table of token rows | `{}` | Complete Agent-row layout overrides keyed by strict canonical agent id. Agents without an override use `ui.sidebar.agents.rows`. |

### Space rows

| Key | Type | Default | Description |
|---|---|---|---|
| `ui.sidebar.spaces.row_gap` | integer | `0` | Blank terminal rows between worktree groups and unrelated top-level Spaces. Worktree parents and their indented children remain packed. |
| `ui.sidebar.spaces.rows` | list of token rows | `[["state_icon", "workspace"], ["branch", "git_status"]]` | Expanded Space sidebar layout. Same format as agent rows. `state_icon` and `git_status` accept fixed styles only. |

Row token entries may be plain strings or inline style tables. Text-valued built-ins and `$name` metadata tokens accept up to 16 ordered rules using `equals`, `contains`, `starts_with`, `gt`, or `lt`; the first match overrides specified styles.

## `[theme]`

Controls the built-in theme and optional per-token color overrides. For appearance auto-switching, `theme.auto_switch` follows the host terminal's light/dark signal and selects between `theme.dark_name` and `theme.light_name`.

### Base theme

| Key | Type | Default | Description |
|---|---|---|---|
| `theme.name` | string | `"catppuccin"` | Built-in theme name. |
| `theme.auto_switch` | boolean | `false` | Follow host terminal light/dark appearance and switch between theme names. |
| `theme.dark_name` | string | unset | Theme name used when `auto_switch` selects a dark appearance. |
| `theme.light_name` | string | unset | Theme name used when `auto_switch` selects a light appearance. |

### Color token overrides

All color keys accept hex (`#89b4fa`), named colors (`cyan`, `blue`), `rgb(r,g,b)`, or reset aliases. Keys under `[theme.custom]` apply on top of the base theme in all modes. Keys under `[theme.custom.dark]` and `[theme.custom.light]` apply after `[theme.custom]` only when `auto_switch` selects that appearance. All default to unset (inherited from the base theme).

#### `[theme.custom]` — universal overrides

| Key | Description |
|---|---|
| `theme.custom.accent` | Accent color. |
| `theme.custom.panel_bg` | Panel background. |
| `theme.custom.sidebar_bg` | Desktop sidebar background without changing other panel surfaces. |
| `theme.custom.active_row_bg` | Active Space and focused Agent row background. |
| `theme.custom.selection_bg` | Navigate-mode cursor row background in the sidebar. |
| `theme.custom.surface0` | `surface0` color token. |
| `theme.custom.surface1` | `surface1` color token. |
| `theme.custom.surface_dim` | `surface_dim` color token. |
| `theme.custom.overlay0` | `overlay0` color token. |
| `theme.custom.overlay1` | `overlay1` color token. |
| `theme.custom.text` | Primary text color. |
| `theme.custom.subtext0` | Secondary text color. |
| `theme.custom.mauve` | `mauve` semantic color. |
| `theme.custom.green` | `green` semantic color. |
| `theme.custom.yellow` | `yellow` semantic color. |
| `theme.custom.red` | `red` semantic color. |
| `theme.custom.blue` | `blue` semantic color. |
| `theme.custom.teal` | `teal` semantic color. |
| `theme.custom.peach` | `peach` semantic color. |

#### `[theme.custom.dark]` and `[theme.custom.light]` — appearance-specific overrides

Same token keys as `[theme.custom]`, prefixed with `theme.custom.dark.` or `theme.custom.light.`. Applied after `[theme.custom]` when `auto_switch` selects the corresponding appearance.

## `[experimental]`

Experimental features that may change or be removed. Enable only the features you need.

| Key | Type | Default | Description |
|---|---|---|---|
| `experimental.allow_nested` | boolean | `false` | Allow launching Herdr inside an existing Herdr pane. |
| `experimental.pane_history` | boolean | `false` | Persist pane screen history to `session-history.json`. |
| `experimental.kitty_graphics` | boolean | unset | Deprecated compatibility key for `terminal.kitty_graphics`. Existing `true`/`false` values remain supported; `terminal.kitty_graphics` takes precedence when both are set. |
| `experimental.reveal_hidden_cursor_for_cjk_ime` | boolean | `false` | Expose the focused pane's cursor anchor to the outer terminal even when the pane requested `?25l`, so macOS native input methods keep tracking the IME candidate window. Trade-off: an extra hardware cursor is visible for apps that hide the cursor without painting a replacement (e.g. Vim normal mode). |
| `experimental.cjk_ime_agents` | list of strings | `[]` | Restrict `reveal_hidden_cursor_for_cjk_ime` to focused panes whose detected agent matches one of these names (case-insensitive). Empty list applies to any focused pane. |
| `experimental.cjk_ime_cursor_shape` | enum | `"steady_block"` | Cursor shape for the IME anchor when `reveal_hidden_cursor_for_cjk_ime` is enabled: `block`, `steady_block`, `underline`, `steady_underline`, `bar`, or `steady_bar`. |
| `experimental.switch_ascii_input_source_in_prefix` | boolean | `false` | While prefix mode is active, temporarily switch the host input source to an ASCII-capable mode so prefix commands are read correctly when an IME is active. macOS and Windows only; on Windows currently limited to the Korean IME. |
